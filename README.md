# ОБА · Рядом

Авторский учебный сайт по основам бизнес-аналитики: основной и продвинутый уровни в одном курсе. Продукт, маркетинг, операции, инвестиции и финансовые посредники разобраны через исходные данные, метод, интерпретацию и практику.

Публикация: [cu.vubni.ru/oba](https://cu.vubni.ru/oba/). Портал импортирует только проверенный Git commit и сохраняет его SHA в `study-sites.json`. Развёртывание выполняет штатный CI портала.

```sh
npm run check
npm run build
npm run dev
```

Сборка не требует установки зависимостей. Формулы отображаются локальной копией KaTeX; текст использует Golos Text. Лицензии находятся рядом с соответствующими файлами в `site/vendor/katex` и `site/fonts`.

Оба уровня хранятся в JSON версии 1 под единственным ключом `ryadom-oba-v1`. Идентификаторы содержат пространство имён `core:` или `advanced:`. Сохранения включают отметки, ответы, заметки и черновики; конфликтующие версии сохраняются отдельно. Общие тема, профиль и место чтения используют runtime платформы. Отдельной авторизации курса нет.

Оригинальные документы, таблицы, презентации и студенческие сдачи отсутствуют в Git и публичной сборке. Матрица источников и числовые сверки ведутся приватно. Полное покрытие курса не заявлено: границы маршрута перечислены на странице «О курсе и покрытии»; официальный формат контрольной не имитируется.
