# ОБА · Рядом

Авторский учебный сайт по основам бизнес-аналитики: основной и продвинутый уровни в одном курсе.

Сайт публикуется в составе [Рядом](https://cu.vubni.ru/oba/). Каждый проверенный импорт фиксируется точным Git commit в каталоге платформы. Оригинальные материалы курса и студенческие работы в репозитории отсутствуют.
